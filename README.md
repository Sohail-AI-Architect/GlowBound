# 🕹️ GlowBound - Neon Browser Arcade Game

A high-performance neon browser arcade game built with Next.js and deployed on Vercel.

🔗 **Play Live Here:** [glow-bound.vercel.app](https://glow-bound.vercel.app)

## 🚀 About The Project
GlowBound is an immersive arcade experience featuring smooth neon visuals, fast-paced mechanics, and responsive controls designed for desktop and mobile viewports.

---
*Built with Next.js, React, and Tailwind CSS.*
